# Security Policy

Focus is a solo project. I take security seriously and appreciate responsible disclosure.

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Instead, email me directly at **konukoii (at) gmail (dot) com** before disclosing publicly. This gives me a chance to investigate and ship a fix before the issue is widely known.

When reporting, please include:

- A clear description of the vulnerability
- Step-by-step instructions to reproduce it
- The environment where you observed it (OS, app version, etc.)
- Any relevant logs, screenshots, or proof-of-concept code

I'll do my best to acknowledge your report promptly and keep you updated as I work on a fix. I genuinely appreciate the help.
